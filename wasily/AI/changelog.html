探索 wasily 的最新动态

随时掌握 wasily 的变化，了解我们为你带来的创新与优化。

2026-11-19 v1.2.0 WASILY 当前版本

新增功能

  • Agent 窗口新增右侧整高快捷图标栏，历史对话、我的产物与插件市场集中在一处，不再悬浮遮挡消息。
  • 新增跨类型知识库检索：文件正文、Word / PDF / Excel / PPT 与图片内容统一检索，支持本地图片理解。
  • 新增更新日志站内页面，帮助与反馈入口不再跳转外部站点。

体验优化

  • 重做 Agent 窗口顶部标题栏：左侧显示会话标题，右侧集中操作按钮，与 Trae 的窗口结构保持一致。
  • 优化历史会话弹层定位，始终贴着历史按钮展开，不再受工作台宽度影响。

问题修复

  • 修复拖动工作台宽度后，悬浮图标位置与工作台不同步的问题。
  • 修复空会话状态下快捷图标栏被误隐藏的问题。
2026-11-04 v1.1.0 WASILY

新增功能

  • IDE 面板新增思考时间线：实时展示思考步骤，完成后收敛为「任务耗时 / 已思考」，可逐行展开查看明细。
  • 支持生成中暂停、回到底部并恢复跟随滚动、错误行定位与运行结果回传。

体验优化

  • 计划卡收进思考折叠区，纯聊天也会生成可点击的耗时行。
  • 历史消息分段加载，长会话滚动更稳定。

问题修复

  • 修复重新生成时重复插入用户消息的问题。
  • 修复面板更新后需要重装扩展才能生效的问题，改为运行时热替换。
