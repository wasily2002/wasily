用户要整理文件时，按以下步骤完整执行，不要停下来确认：

## 第一步：全面盘点
1. file_list 目标根目录，拿到所有文件/子文件夹
2. 统计根目录散落文件数、按类型（扩展名）分组计数
3. 列出重复文件（同名或同MD5）、带(1)后缀的、哈希命名无意义的

## 第二步：分类方案（基于盘点结果自动决定）
常见分类目标文件夹：
- 图片截图 → 参考资料/截图/
- 微信图片 → 参考资料/微信截图/
- PDF文档 → 文档/
- HTML网页 → 项目文件/
- 哈希命名图片（013a6f60xxx.webp 这种）→ 设计素材/
- 临时调试文件（tmp_debug/、_bak/、.tmp）→ 直接删除

## 第三步：执行
1. 先 file_list 检查目标文件夹是否存在，不存在 file_write 或用 shell_exec mkdir 创建
2. 用 file_move 批量移动（src 是当前位置，dst 是目标文件夹+文件名）
3. 重复文件保留有意义的名字，删多余的
4. 垃圾目录用 file_delete 删掉
5. 最后 file_list 验证根目录是否清空

## 第四步：汇报
一句话：整理前根目录 X 个散落文件，整理后 0 个，分到 N 个新文件夹，删了 M 个重复/垃圾文件。

禁止：只给方案不动手、等用户确认每一步、漏了根目录散落文件。
