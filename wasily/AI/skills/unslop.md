# unslop：让编程产出的页面变好看

作者 Damir Sokolovsky（@heydamir），CC BY 4.0，完整原文在 skills/unslop/SKILL.md。

## 原则
保留功能、内容与区块顺序，只改工艺：每一个尺寸、颜色、词和图像都要有理由。
界面外壳保持安静，把质感集中到 1-2 个「内容高光」上；干净但换个产品也成立 = 下一个模板。

## 先看再改
1. 找到渲染这个页面的文件；能渲染/截图就先看真实效果，别只读代码。
2. 按 skills/unslop/references/signs.md 列 slop 清单：每条写清「问题 + 文件位置」。
3. 判断程度：重度（走完整流程）/ 轻度（只修清单项，沿用现有品牌）/ 无 slop（直说，只给 2-3 条精确建议）。
4. 定方向（先给用户确认再改）：产品（做什么·给谁）、性格（2-3 个具体词，禁止 clean/modern/premium 这类空话）、世界（材质场景，决定中性色倾向与强调色）、高光（1-2 处可以有颜色和材质的地方）、签名细节（只此产品有的一处）。

## 九轮修复（顺序不可颠倒）
1. 间距：4px 网格；同类同尺寸；组内间距 < 组间间距；图标一列、标签一行、数字右对齐；导航行高 32-36、图标列固定；删掉 mt-[13px]、py-[11px] 这类一次性值。
2. 颜色：一条中性色阶（石墨/暖/墨），文字三级 primary/secondary/muted；外壳只留 1 个强调色用于主操作/选中/关键数字；禁止色相渐变、渐变文字、发光、彩色阴影、径向色斑、霓虹边框；分隔线用文字色 6-10% 透明度；暗色深度靠表面层级+细线，不靠阴影。
3. 图标：emoji 全部换线性图标（优先 lucide）；统一 16/18px、1.5 描边；继承文字色；图标盒宽度与图标到标签间距（8/10）固定。
4. 文案：标题说清「为谁做什么」；禁感叹号、禁 Welcome back 👋 式问候、禁 supercharge/seamless/unlock/AI-powered 等虚词；短标签不写省略号；数字带对比基准（+12% vs 上月）；假数据要像真的，禁 [X]/123,456。
5. 字体：界面 1 个家族 + 最多 1 个搭档（等宽/展示）；400/500 为主，600 极少；层级靠字号与颜色；句首大写，禁全大写+宽字距标签；小字禁负字距；数字 tabular-nums 且全屏格式统一。
6. 布局：保留区块与顺序；应用/仪表盘保持真实比例（侧栏 240-280、内容流式、1440-1600 上限），不要把应用塞进窄居中列；hero 用整幅场景图或非对称分栏+产品预览，禁「全部居中堆叠」；标题左对齐；1 主操作 + 至多 1 次操作。
7. 细节：嵌套圆角 = 外圆角 - 内边距（≥4）；控件 8-10、卡片 12-16、面板 14-20，不是所有东西都药丸；计数用低调 mono 文字不用发光胶囊；图表一条中性网格、仅 1 个强调色；统计卡 = 标签 + 大数字 + 对比，不塞迷你图/图标；卡片尺寸有节奏，禁等宽同构；选中态 = 表面层级 + 细线。
8. 视觉：删玻璃球、光斑、星云、发光网格、全息机器人；落地页要一张说明产品的真实场景图（留空给标题）；仪表盘用产品自身内容当高光（精致图表、真实数据、材质对象）；没有图像工具就用代码搭建，写好图片提示词并留出尺寸正确的空位。
9. 动效：删 loop 动效（pulse/ping）、shimmer、漂浮、视差、transition-all、卡片的 hover:scale；只保留能解释的动效；transition 写明属性，不改 width/height/top/left/margin；全屏一条缓动曲线、少量时长。

## 硬性禁止
色相渐变 / 渐变文字 / 发光 / 彩色阴影 / emoji 当图标 / 全大写宽字距标签 / 感叹号 / 编造功能与数据 / 玻璃拟态与霓虹堆砌 / 修完再用另一种潮流补装饰。
