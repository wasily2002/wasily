双形态，同一套数据

Agent 窗口以任务为中心，适合批量推进与变更审核；IDE 窗口以代码为中心， 适合逐文件精读与调试。两者共享任务、会话与配置，切换不丢上下文。

  • 任务进度与产物在网页端、桌面端同步
  • 会话可跨端续聊，历史记录随时接上
  • 知识库与工具调用对两种形态同时开放

开发工具链与安全

保留传统 IDE 的掌控感，同时把风险挡在执行之前。

工具链

  • 代码编辑、运行与调试
  • Git 工作流与 AI 提交信息
  • 变更审查：摘要、流程图、diff
  • 插件扩展与远程开发

安全能力

  • 隐私模式：对话与代码不参与训练
  • 权限审批：高风险命令执行前拦截
  • 本地优先：文件始终留在本机
  • 操作留痕：日志按启动会话归档
